# 深度学习与大模型课程主页

华中科技大学“深度学习与大模型”课程的静态主页。页面包含分点课程简介、2027 年春季教学安排与预留的教学团队区域。

课程主页已根据 2027 年春季教学日历更新：面向强基2501、智科2501-2502，共 16 个节次、32 学时。教学安排按节次展示课程主题、学时与 Slides；课件入口预留，尚未上传文件。教学团队暂留空白。

源教学日历 Word 文档不纳入本仓库，也不在课程主页提供下载。

## 本地预览

项目不需要构建步骤或第三方依赖。推荐在仓库根目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。直接双击 `index.html` 也可查看基础页面，但使用静态服务器更接近 GitHub Pages 的加载方式。

所有站内资源使用相对路径，适用于 GitHub Pages 的项目站点路径。

## 内容维护

- 更新教学日历：根据课程组确认的信息编辑 `index.html` 中的 `#schedule` 表格，并同步核对课程简介与课程信息。
- 上传正式课件：将文件放入 `slides/` 目录，在对应节次的 Slides 单元格中，将待上传占位替换为真实相对链接，例如 `<a class="slides-link" href="slides/lecture-01.pdf">[slides 1]</a>`。上传文件后再启用链接，并移除该节次的“待上传”文字。
- 发布教学团队：课程组确认人员信息后，再补充 `#team` 内容。当前仅保留板块标题。
- 更新品牌图片：保持现有文件名，优先使用学校或学院正式提供的资源，并保留清晰度和长宽比。

新增内容时，请继续明确区分已确认信息和待发布事项，不要把尚未提供的课程材料写成可下载链接。

## 发布前检查

1. 核对所有课程事实、日期、人员和联系方式。
2. 检查站内锚点、外部链接和资源文件是否可访问。
3. 在约 360 px、768 px 和 1440 px 宽度下检查布局。
4. 使用键盘操作导航和课件链接，并检查焦点是否清晰可见。
5. 确认图片替代文本、表格标题和页面标题符合实际内容。

## GitHub Pages 发布

本项目可直接由 `main` 分支根目录发布，无需构建工作流：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/(root)`，然后保存。
4. GitHub Pages 完成发布后，通过页面提供的项目站点地址访问。

若仓库的默认分支或文件目录发生变化，应同步调整上述 Pages 设置。自定义域名配置由仓库维护者统一管理。
