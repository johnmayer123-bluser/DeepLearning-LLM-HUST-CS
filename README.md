# 深度学习与大模型课程主页

华中科技大学“深度学习与大模型”课程的静态主页。页面以课程导览为主，包含课程简介、示例教学安排、作业与项目、学习资源及教学团队信息区。

> 当前教学主题和任务是用于搭建主页信息结构的**示例安排**。正式周次、教师信息、上课地点、考核方式、截止时间与课程材料必须由课程组确认后再发布。

## 本地预览

项目不需要构建步骤或第三方依赖。推荐在仓库根目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。直接双击 `index.html` 也可查看基础页面，但使用静态服务器更接近 GitHub Pages 的加载方式。

## 文件结构

```text
.
├── index.html             # 页面内容与语义结构
├── styles.css             # 响应式视觉样式
├── script.js              # 移动导航、对话框等交互
└── assets/
    ├── hust-logo.svg      # 华中科技大学标识
    ├── hust-cs-logo.png   # 计算机科学与技术学院标识
    └── course-map.svg     # 课程技术路线图
```

所有站内资源使用相对路径，适用于 GitHub Pages 的项目站点路径。

## 内容维护

- 修改课程主题和示例任务：编辑 `index.html` 中的 `#schedule` 表格。
- 上传正式课件：将文件放入明确的资源目录，并把“待更新”状态替换为真实相对链接；不要创建尚不存在的下载地址。
- 发布公告：替换公告区的示例文案，并同步更新对应的 `<dialog>` 内容。
- 发布教学团队：课程组确认姓名、角色与公开联系方式后，再替换 `#team` 占位内容。
- 更新品牌图片：保持现有文件名，优先使用学校或学院正式提供的资源，并保留清晰度和长宽比。

新增内容时，请继续明确区分正式信息、示例内容和待确认事项。

## 发布前检查

1. 核对所有课程事实、日期、人员和联系方式。
2. 检查站内锚点、外部链接和资源文件是否可访问。
3. 在约 360 px、768 px 和 1440 px 宽度下检查布局。
4. 使用键盘操作导航、按钮与对话框，并检查焦点是否清晰可见。
5. 确认图片替代文本、表格标题和页面标题符合实际内容。

## GitHub Pages 发布

本项目可直接由 `main` 分支根目录发布，无需构建工作流：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/(root)`，然后保存。
4. GitHub Pages 完成发布后，通过页面提供的项目站点地址访问。

若仓库的默认分支或文件目录发生变化，应同步调整上述 Pages 设置。自定义域名配置由仓库维护者统一管理。
